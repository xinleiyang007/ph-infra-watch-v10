# V10 质量保证与数据边界

- 核心清洗：新闻按规范化标题严格去重，同标题来自多个 RSS 会合并覆盖来源；**不同措辞描述同一事件尚未可靠自动归并**，不能宣称已具备通用的事件级语义去重。
- 25 个媒体/公告入口取自 V9 配置。`source_method=rss` 才是媒体原生 RSS；`google_news_search` 是第三方公开索引，不能作为“已直接采集该媒体”宣传。
- 266 个项目与 227 条企业档案来自上一版完整源码，不是新一轮实时全面验证；涉及投资方、总包和分包商的缺失资料仍保持空值。
- 文档提取器支持文字版 PDF 与 XLSX；图片扫描 PDF、登录限制和反爬阻止可能导致失败。没有做 OCR，不对扫描版提取效果作保证。
- 新闻采集时间 `media_status.generated_at`、原始新闻发布时间 `published_at`、项目记录的资料日期 `projects[].source_date` 属于不同字段，不互换。
- 网页刷新是最新发布 JSON 检索，后台采集通过 GitHub Actions 手动或调度触发。无浏览器内秘密 token。
- Argos 翻译失败时继续发布英文原文并显示待翻译；可选 Gemini 仅基于标题和短 RSS 内容总结，必须保持来源 URL。
- GitHub Actions 不向源代码分支自动提交采集快照，避免从前的 GitHub Desktop 冲突；但持久历史来自之前 Pages 发布快照，仍存在失效风险。
- 示例新闻只用于本地浏览器测试截图，正式 `data/media_leads.json` 初始是空列表。
